Applies to: all engines; all production periods

The normal windscreen wiping system works properly, using the controls through the steering column switch unit lever, but it is not activated through the rain sensor.

Applies to: all engines; all production periods

The networks go on stand-by 30 mins after the engine has been switched off. This makes it impossible to carry out the fault diagnosis. If a diagnostic session has to be opened, start up the engine to reawaken the networks

Applies to: all engines; all production periods
