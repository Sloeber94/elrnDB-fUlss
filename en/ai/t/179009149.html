Description

The two sliding side doors can be opened/closed electrically from the inside:

  • from the front seats using the buttons next to the courtesy light
  • from the centre seats using the buttons on the appropriate door pillar.

When the button is pressed, the lock unlocks and the sliding door opens; when the button is pressed again, the door closes.

The sliding side doors can be opened electrically using the special button on the remote control.

The remote control built into the key on the version in question has 4 buttons:

  • one for activating the (locking) command for the central locking, for switching on the alarm and for the location function < R1 > < R2 >(Wiring Diagram ) E7015 ALARM
  • one for activating the unlocking of the central locking and for switching off the alarm < R1 > < R2 >(Wiring Diagram ) E7015 ALARM
  • one for opening/closing the right sliding side door
  • one for opening/closing the left sliding side door

The remote control receiver aerial is incoropated in the steering column switch unit (steering wheel node); the activation and/or deactivation information is sent to the Body Computer via the CAN.

Both the sliding doors are fitted with an anti-crush safety sensor which intervenes according to two different operating logics:

  • during opening: if there is an obstacle, the door automatically stops;
  • during closing: if there is an obstacle, the door stops and automatically reverses direction, opening fully.

In this case, to restore correct operation, an electric command must be given using the remote control buttons or one of the buttons in the vehicle.

In addition, for safety reasons, a special "locking" switch, located on the driver's front door, allows the opening/closing of the sliding doors (as well as the operation of the electric windows in the rear doors < R1 > and the rear sun roofs < R2 > to be excluded so that their operation can be prevented, for example if children are present.

See E3060 SUN ROOF

The operating logic described above is controlled by the sliding door node which supervises the operation of the two movement motors for each door: one unlocks the lock, the other moves the door by means of a geared motor or two cables connected to the door guide pulley

The initialization procedure is carried out in the following cases:

  • battery disconnection,
  • removing/refitting sliding door motor.

To initialize the system it is necessary to:

  • start with the door closed;
  • control an opening (electrical);
  • control a closing (electrical);
  • control another opening (electrical).

the initialization is not lost from the system after the door is closed manually.
