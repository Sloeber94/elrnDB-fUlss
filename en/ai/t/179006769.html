Applies to: all engines; all production periods

With the vehicle moving there is a smell of exhaust gas coming from the rear area.

Applies to: all engines; all production periods

The test should be carried out in the following conditions: vehicle speed 50 km/h, door windows closed, air conditioning system recirculation off. Carry out various pull and release tests

Applies to: all engines; all production periods
