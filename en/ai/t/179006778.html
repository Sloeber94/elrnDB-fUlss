The engine seems to be running smoothly, but the fuel consumption is higher than ever before.

Applies to: engines: 2.0 16V JTD, 2.2 16V JTD; all production periods

The fuel consumption figures in the technical documentation have been defined during the couse of homologation tests.These tests simulate an urban cycle and an average non-urban cycle and therefore may not be representative as fuel consumption depends a great deal on driving styles.

Applies to: engines: 2.0 16V JTD, 2.2 16V JTD; all production periods

TEST RESULTS

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following conditions:

  • condition of the air filter;
  • the fuel filter.
  • Check the exhaust circuit paying particular attention to any obstructions in the pipes

Move on to Step

1. Filter element dirty or damaged

1. Replace the filter element

Op. 1048A14 AIR CLEANER FILTERING ELEMENT - REPLACE.

2. Fuel filter dirty

2. Replace the filter element

Op. 1044B10 FUEL FILTER ASSEMBLY - R + R OR REPLACE

3. Exhaust system obstructed

3. Replace the defective system component

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic connector and check the following at the engine management node:in errors ambient

  • that there are no faults;

in parameters ambient

  • the plausibility of all the parameters.

Move on to Step

Error detected in the control unit

Continue following the instructions for the diagnostic equipment

3

LOW PRESSURE CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the fuel supply circuit, low pressure side:

    Move on to Step

    1. Pressure not correct: fuel filter faulty

    1. Replace the fuel filter

    Op. 1048A10 AIR CLEANER FILTERING ELEMENT - REPLACE

    2. Pressure not correct: electric pump faulty

    2. Replace the electric pump

    Op. 1040A70 SUBMERGED PUMP ASSEMBLY COMPLETE WITH LEVEL GUAGE CONTROL - R + R

    3. Pressure not correct: fuel return pipe faulty

    3. Replace the pipes concerned
