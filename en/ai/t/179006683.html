Applies to: all engines; all production periods

The direction indicators are controlled by the Steering Wheel Controls Node NVO and activated by the Body Computer Node BSI. Whilst the hazard warning lights are controlled by the Instrument Panel Node NQS.

Applies to: all engines; all production periods

ERRORS CHECK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in the Body Computer ambient, check whether one or more of the following errors are present:

  • Connection error with steering column switch unit lights.
  • VAN CON and CAR relays.
  • VAN CONF : connection with Instrument Panel
  • Control inconsistency

1. Left/right direction indicators relay error detected.

2. Connection error with steering column switch unit module detected.

Move on to Step

3. Connection error with VAN CON and CAR network detected.

Move on to Step

4. Connection error with Instrument Panel

See table K95 WARNING LIGHT SYMBOLS DO NOT COME ON / (IN INSTRUMENT PANEL)

5. Control inconsistency error.

5. Continue as described by the diagnostic equipment.

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner check, in the Steering Wheel Controls Node ambient, that the state of the parameters varies when the controls are activated.

Move on to Step

1. There is no variation in the state of the parameters under consideration.

1. Replace the Steering Wheel Controls Node control unit.

2. There is no variation in the state of the parameters under consideration.

Move on to Step

6

CONTROL UNIT ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the electrical circuit for the Steering Wheel Controls Node in the following order:

  • Presence of battery positive at the network connection
  • Protective/supply fuse(s).
  • Wiring between the Body Computer and the Steering Wheel Controls Node.
  • Control unit earth.

Move on to Step

1. Control unit faulty.

1. Replace the Steering Wheel Controls Node control unit.

2. Protective fuse/s blown

2. Replace the component involved (in the case of a fuse, find out what caused it to blow).

3. Wiring defective

3.Renew the wiring

4. Control unit earth faulty

4. Restore the correct operation of the control unit earth

7

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
