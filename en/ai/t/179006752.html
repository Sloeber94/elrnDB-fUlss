PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check whether the CONNECT operates when the switch is turned on or the key is turned to ON

Move on to Step 2.

It does not work with the ignition key in the ON position and/or the on button.

Move on to Step 1.

It works but the LED above the SOS button is on constantly: press the DARK button for a while (until the system switches off).

Replace the CONNECT.

Op. 5580P20 CENTRALINA DEL CONNECT - S.R.

Italian market: contact TESEO.

It works but the system continues to "beep": check that the VIN code is correct (it is written on the passenger door pillar); also check, using the Examiner, whether the code is correctly entered in the control unit.

Replace the Body Computer

Op. 5505A32 BODY COMPUTER - R R

or the CONNECT
