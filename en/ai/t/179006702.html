Applies to: all engines; all production periods

The interior lights do not work correctly when the controls are operated.

Applies to: all engines; all production periods

The vehicle interior lights are controlled by the Body Computer Node BSI.

Applies to: all engines; all production periods

ALL OK

Connect the Examiner diagnostic equipment and check, in the Body Computer ambient, that there are no errors and the following parameters are present:

ERRORS CHECK

ALL OK

Check for the presence of one or more of the following errors using the Examiner in the Body Computer ambient:

  • Boot/courtesy light control error

ALL OK

ACTION

  • Courtesy light operation.

1. Impossible to activate all the boot/courtesy lights.

1. Restore the correct setting/functions in the Body Computer.

2. Impossible to activate one of the boot/courtesy lights.
