One of the sliding side doors (NPS) opens manually, not automatically (electric).

Applies to: all engines; all production periods

The vehicle uses a door activation and deactivation system with data transfer via specific CAN/VAN networks.

CHECK CONTROLS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in Texton sliding door "Parameter Reading" mode, check changes in the following parameters for the door under examination:

  • Left and right front key
  • Left and right rear key
  • Left and right door motor control
  • Power supply to left and right slide sensor

Move on to Step

1. Left and/or right front button faulty

1. Renew the wiring and/or replace the button.

2. Left and/or right door motor faulty.

2. Renew the wiring and/or replace the button.

3. Left and/or right sliding sensor power supply faulty.

Move on to Step

CHECK ERRORS

PROBLEMS ENCOUNTERED

ACTION

With the Examiner "Error reading" mode for the Texton sliding doors, check for one or more of the following errors:

  • Control unit
  • Battery voltage out of range
  • Sensor power supply
  • Left and/or right front key
  • Left and/or right rear key
  • Left and/or right catch
  • Left and/or right slide sensor Pin S1
  • Left and/or right slide sensor Pin S2
  • Left and/or right door actuator control
  • Left and/or right door motor control
  • Left and/or right brake control
  • Left and/or right door initialisation

CHECK CONTROL UNIT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With Examiner in Active Diagnostics mode for Texton sliding doors, activate the buzzer and side doors.

See E3090 PARKING SENSOR

Move on to Step

1. Fault in buzzer

1. Replace PLS control unit

2. Fault in both doors, power fuses blown.

2. Eliminate any short circuits and then replace power fuse/s. Repair wiring and/or replace PLS control unit.

3. Fault in one side door

3. Eliminate any short circuits and then change power fuse/s

4. Fault in PLS control unit

4. Restore wiring and/or replace the actuation control unit.

7

OPERATION CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Activate the side door under examination and check for:

  • side door motor activation.
  • side door brake/clutch activation.
  • side door position sensor activation [Test 7010AB].

Move on to Step

1. Power fuse/s blown

1. Eliminate any short circuits and then change power fuse/s

2. Brake/clutch power supply, engine activation and sensor signals are present but side door will not activate.

2. Restore wiring and/or replace the actuation control unit.

CHECK ON CORRECT OPERATION

ALL OK

ACTION

Check that the fault is no longer present.

Fault persists
