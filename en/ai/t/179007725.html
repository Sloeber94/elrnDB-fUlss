1. Disconnect the electrical connections for the sliding side door opening/closing motors.

Applies to: all engines; all production periods

1. Disconnect the end of the link controlling release of the device holding the sliding door open from the sliding door opening/closure mechanism.

Applies to: all engines; all production periods

1. Disconnect the end of the catch control link from the sliding door opening/closure mechanism

Applies to: all engines; all production periods

1. Release the catch control link from the retaining clips and release the rubber seal from the door frame.

Applies to: all engines; all production periods

1. When the sliding door is open, unscrew the bolts fastening the catch.

Applies to: all engines; all production periods

1. Working from inside the vehicle, withdraw the catch, release the control link from the catch.

Applies to: all engines; all production periods

Refitting

Removing

- Connect the rod to the lock.

Carry out the operation described above with the help of a second mechanic.

- Position the catch inside the frame and secure by tightening the bolts from the outside.

- Fit the catch control link rubber seal in its seat.

- Attach the catch link to the retaining clips on the door frame and mechanism.

- Connect the end of the link controlling release of the device holding the sliding door open to the mechanism.

- Connect the electrical connections for the sliding side door opening/closing motors.

- Connect the negative battery terminal.
