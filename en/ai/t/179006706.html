J03 SCREEN WASHER NOT WORKING

Applies to: all engines; all production periods

With the ignition on, when the windscreen washer control is operated it does not work and the windscreen is not washed

Applies to: all engines; all production periods

The same pump manages the front and rear screen washer functions.The networks go on stand-by 30 mins after the engine has been switched off. This makes it impossible to carry out the fault diagnosis. If a diagnostic session has to be opened, start up the engine to reawaken the networks

Applies to: all engines; all production periods
