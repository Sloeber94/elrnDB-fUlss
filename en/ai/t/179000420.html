INTRODUCTION

The CD Changer, located in the dashboard oddments compartment, has the task of reading the numerical information contained on the CDs and converting it into analogue audio electrical signals that can be read by the radio/Connect equipment. The system includes a CD player / changer, an extractable cartridge for 6 CDs and a CD eject button that is lit up.

The CD module converses with the other devices on the VAN Confort network in order to carry out the commands sent, provide information concerning its own status and indicate any changes. The dialogue with the other devices only takes place via the NSC (multifunction screen node).

In the case of problems, the CD changer has an automatic reset function available for the software and notifies the radio of a possible fault through messages displayed on the NSC multifunction screen (disc not introduced correctly, high temperature, etc.).

Ten seconds after the power supply (+30) has arrived, the CD changer undergoes a compulsory automatic initialization stage. This period is necessary to ensure the correct operation of the module.

Operating procedure

Stop mode

This command has priority over all other commands received.

Having received the STOP signal, the changer interrupts the reading in order not to wear out the head, keeping the position at the time of stopping in its memory in order to be able to resume from the same point later on.

Pause mode

In this mode the changer does not read the CD but the latter continues to turn and the head remains in the same position in order to resume from the same point.

Normal reading mode

The CD changer reads the CD tracks normally in order.

Fast forward or backward reading mode

Following a fast forward or reverse command, the CD changer starts the acceleration procedure. The radio volume is turned down in this mode. The procedure can only be cancelled if a reading in normal mode or pause command is received.

Sequential reading of introduction of tracks mode

The listening time for each introduction is 10 seconds. The procedure can only be cancelled if a reading in normal mode or pause command is received.

Reading mode

The CD changer (normal, fast foward or backward, introduction of the tracks) should manage the succession of tracks depending on the mode requested. The succession modes are indicated via the VAN.

Random track mode

The tracks on a disc are played in random order. Once all the tracks on a CD have been played, the next CD is played or, if that was the last CD, then the first one is played.

Random CD mode

The tracks on a disc are played in order. After the last track, the move to another CD is random.

Track repetition mode

The tracks on a CD are played in sequence.

CD repetition mode

All the tracks on a CD are played in order.

Eject control

The CD changer has a CD eject button. This button is lit up and the lighting logic depends on the state of the connections.

If the +VAN signal is present, the warning light is on whilst if the signal is interrupted the warning light remains on for 10 minutes and then goes out. The CDs can be removed in this condition.
