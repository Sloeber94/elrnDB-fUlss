Operational Description

When the key is turned to position M, the aerial P091 (pins 4, 6 connector B) supplies an encrypted bod contained in the ignition key to steering wheel control unit M093 (pins 4, 6 connector E).

Pins 1, 3 connector A of steering wheel node control unit M093 communicates the key code to body computer node M001 (pins 38, 40 connector L) via the CAN.

The steering wheel node control unit M093 receives a supply (pin 5 connector A) through the line protected by fuse F11, located in the body computer node M001; it receives a supply via the CAN (pin 6 connector A) from the line protected by fuse F16, located in the body computer node M001.

This information is sent on via the CAN to engine control unit M010 (pins A3, A4 connector A), which checks that the code received is correct.

If the code is correct, the engine management control unit M010 allows the engine to be started

See E5010 STARTING AND RECHARING
