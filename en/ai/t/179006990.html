1040B58 FUEL RETURN LINE FROM INJECTION PUMP TO FILTER - R R

Applies to: engines: 2.0 16V JTD; all production periods

Removing

Refitting

See in Op. 1040B10

1. Remove the band and disconnect the return pipe from the pressure pump.

2. Disconnect the injector return pipe.

3. Disconnect the rapid connector from the fuel manifold.

4. Remove the pipe.

Applies to: engines: 2.0 16V JTD; all production periods

Refitting

Removing

- Fit the fuel return pipe from the pump to the filter and connect the rapid connector to the fuel manifold.

- Connect the injector return pipe.

- Connect the pipe to the pressure pump.

See in Op. 1040B10

Applies to: engines: 2.2 16V JTD; all production periods
