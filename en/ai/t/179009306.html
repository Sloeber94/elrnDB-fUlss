Applies to: all engines; all production periods

Description

The electronically controlled Cruise Control system makes it possible to drive the vehicle at the desired speed without pressing the accelerator pedal.

This makes driving on motorways less tiring, especially on long journies, because the speed memorized is maintained automatically.

The device can only be switched on at speeds above 40 km/h or in 4th or 5th gear.The function is managed by the engine control unit. This receives commands from a Cruise Control lever on the left of the steering wheel.

The function is engaged by turning the wheel (ON).

When a speed is set ( SET + , SET - ), the setting is saved and may be called up at any time ( RCL ).

The function is automatically deactivated:

  • by pressing the brake pedal;
  • by pressing the clutch pedal;
  • by turning the wheel to OFF;
  • by switching off the engine;

In such cases, the last speed achieved is stored and can be recalled by pressing the RCL button.

The system also deactivates at speeds below the minimum permitted speed (about 30 km/h).

The Cruise Control lever is incorporated in the steering column switch unit (steering wheel node); the activation, deactivation information, etc. is sent via the CAN to the Body Computer.

With the system activated, the milometer warning lights node warning light is lit up.

there is a second "redundant" switch located on the brake pedal, used by the engine management control unit, in particular, for the Cruise Control functionThe "basic" switch (I030) is the "normally open" type (when the pedal is pressed, the switch closes), whilst the "redundant" switch (I035) is the "normally closed" type (when the pedal is pressed, the switch contact opens): the system checks the consistency of the "pedal pressed" information in this way.
