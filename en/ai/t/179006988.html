1040B55 INTERMEDIATE FUEL RETURN PIPE R R

Applies to: engines: 2.0 16V JTD; all production periods

Removing

Refitting

- Position the vehicle on a lift.

- Raise the vehicle.

1. Disconnect the intermediate return pipe rapid connector from the fuel cooling device.

Applies to: engines: 2.0 16V JTD; all production periods

1. Disconnect the rapid connector connected to the return return pipe.

2. Release the intermediate fuel return pipe from the retaining bands and remove it.

Applies to: engines: 2.0 16V JTD; all production periods

Refitting

Removing

- Connect the rapid connector for the intermediate fuel return pipe to the rear return pipe and to the cooling device.

- Lower the vehicle on the lift.
