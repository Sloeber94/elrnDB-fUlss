Applies to: engines: 2.0 16V JTD, 2.2 16V JTD; all production periods; only with equipment: MY 2005

The two sliding side doors can be opened/closed electrically from the inside:

- from the front seats using the buttons next to the courtesy light

- from the centre seats using the buttons on the appropriate door pillar.

When the button is pressed, the lock IS unlocked and the door opens; when the button is pressed again, the door closes.

The same operations can also be carried out using the remote control.

The remote control incorporated in the key has 4 buttons:

- one for activating the central locking (locking) command, switching on the alarm and the location function;

- one for activating the release of the central locking and switching off the alarm;

See E3040 CENTRAL LOCKING

See E7015 ALARM

- one for opening/closing the right sliding side door;

- one for opening/closing the left sliding side door.

The remote control receiver aerial is incorpated in the steering column switch unit (steering wheel node); the activation and/or deactivation information is sent to the Body Computer via the CAN.

Both the sliding doors are fitted with an anti-crush safety sensor which intervenes according to two different operating logics:- during opening: if there is an obstacle, the door automatically stops;- during closing: if there is an obstacle, the door stops and automatically reverses direction returning it to the original position.In this case, to restore correct operation, the command must be given using the special buttons on the remote control or from inside the vehicle.

For safety reasons, a special "locking" switch, located on the driver's front door, allows the exclusion of the opening/closing of the sliding side doors, the operation of the windows in the rear doors and the rear sun roofs: this is a useful function, for example if children are present.

See E3051 ELECTRIC REAR WINDOWS

See E3060 SUN ROOF

The operating logic described above is controlled by the sliding door node which supervises the operation of the two movement motors for each door: one unlocks the lock, the other produces the movement with the help of two cables connected to the guide pulley.

The initialization procedure is carried out in the following cases:

- battery disconnection,

- removing/refitting sliding door motor.

To initialize the system it is necessary to:

- start with the door closed;

- control an opening (electrical);

- control a closing (electrical);

- control another opening (electrical).

The initialization is not lost from the system after the door is closed manually.
