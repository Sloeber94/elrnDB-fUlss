The alarm comes on normally but the doors not lock (using the remote control)

Applies to: all engines; all production periods

The alarm system comes on automatically the moment the doors are locked using the remote control.The command to lock the doors and boot comes from the Body Computer Node to the Driver's Door Node, Passenger Door Node and Sliding Doors Node.If the door is not correctly closed or this status is signalled by the door sensor, the doors cannot be locked and the alarm switched on and this is signalled by an auditory warning.The networks are on stand-by 30 mins after the engine is switched off. This makes it impossible to carry out the fault diagnosis. If a diagnostic session has to be opened, start up the engine to reawaken the networks.

Applies to: all engines; all production periods
