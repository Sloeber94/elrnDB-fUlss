Applies to: all engines; all production periods

Description

The door mirrors can be electrically adjusted in two directions using a joystick located in the door controls on the driver's side.

Both mirrors are adjusted using the joystick which moves in four directions: firstly the mirror to be adjusted (left or right) is selected, then the mirror selected is adjusted.

Moving the joystick backwards (by around 120°) folds the mirrors, moving it forwards, returns them to the open position.

The joystick controls three electrical motors located in each of the two mirrors: one motor allows the rotation of the mirror on the horizontal axis, another on the vertical axis and the third controls the folding.

The door mirrors are controlled by the door control units in accordance with the control logic transmitted by the body computer via the CAN.

The mirrors can only be adjusted with the key in position M.

The interior rear view mirror is the electrochrome type: i.e. it contains an electronic device which controls the automatic anti-glare function.

The automatic mode is produced by pressing the button on the actual mirror; an LED signals that it is on.

In order to ensure optimum visibility during manoeuvres, the interior mirror switches to automatic mode each time reverse gear is engaged.
