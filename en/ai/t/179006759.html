Applies to: all engines; all production periods

When the central locking is activated using the key or the remote control sometimes the doors are not locked or they are not locked correctly

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

1

DOOR ADJUSTMENT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the door handle pulled, close the door several times checking that the lock does not interfere with the striker and that both lock catches are engaged

Move on to Step

The lock interferes with the striker and both catches are not engaged

Adjust the striker for the door concerned

2

DOOR OPENING CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the door opens/closes correctly using the key

Move on to Step

When the key is operated, the closing takes place during the last section of the operation

Move on to Step

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
