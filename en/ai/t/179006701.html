Applies to: all engines; all production periods

The interior lights do not work with the timer when the controls are operated. The vehicle interior lights are controlled by the Body Computer Node BSI.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

1

BATTERY VOLTAGE CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the battery voltage is correct.

Move on to Step

Battery voltage not correct.

Restore the correct voltage.

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment and check, in Body Computer ambient, that there are no errors and that the parameters are present.

Move on to Step

1. Impossible to connect with the control unit.

1. Replace the Body Computer control unit.

2. Presence of errors.

Move on to Step

3

ERRORS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner in Body Computer ambient, check for the presence of one or more of the following errors:

  • Boot/courtesy light error

Move on to Step

Boot/courtesy light error detected.

Continue as described in the table

See table I50 INTERIOR LIGHTS NOT WORKING / UNDER NO CIRCUMSTANCES

4

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in the Body Computer ambient, check in Active Diagnosis that the activation of the function in question is correct.

  • Boot light operation.
  • Courtesy light operation.

Move on to Step

1. Impossible to activate all the boot / courtesy lights with the timer.

1. Restore the correct setting/functions in the Body Computer.

2. Impossible to active one boot/courtesy light.

2. Continue as described in the table

See table I50 INTERIOR LIGHTS NOT WORKING / UNDER NO CIRCUMSTANCES

5

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

Fault persists

Replace the Body Computer control unit.
