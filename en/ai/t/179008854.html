Description

The rearscreen wiper is activated by turning the ring nut on the end of the lever on the right of the steering wheel.

The operation of the rearscreen wiper motor is controlled intermittently by the electronic device that also manages the windscreen wash/wipe function.

Pushing the lever gently towards the steering wheel activates the rearscreen washer function, via the windscreen washer (two way) pump, which rotates in the opposite direction and sends the detergent fluid towards the back following the same control logic: the rearscreen wiper is activated and then, when the rearscreen washer command ends, an additional stroke is carried out.

With the windscreen wipers working, if reverse gear is engaged, the rearscreen wiper is automatically activated: this function is managed by the Body Computer which sends the steering column switch unit electronic device this information coming from the reversing lights function control logic [EL2022].

See E2022 REVERSING LIGHTS

The rearscreen wash/wipe function can only be activated with the key in position M.
