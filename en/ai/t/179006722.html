Applies to: all engines; all production periods

With the ignition ON, the minimum engine oil pressure warning light on the steering column does not come on or it is on constantly.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the operation of the engine oil pump, in particular:

  • Correct oil level.
  • Engine oil pressure check.

Move on to Step

1. Engine oil level not correct.

1. Restore the correct engine oil level.

2. Engine oil pump faulty.

2.

See table X05 EXCESSIVE OIL CONSUMPTION

1

BATTERY VOLTAGE CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the battery voltage is correct.

Move on to Step

Battery voltage not correct.

Restore the correct voltage.

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment and check, in the BTO Milometer Warning Lights Node ambient, that there are no errors and that the parameters are present.

Move on to Step

1. Impossible to connect with the control unit.

Move on to Step

2. Errors detected

Move on to Step

3

ERRORS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check for the presence of one or more of the following errors using the Examiner in the Milometer Warning Lights Node ambient:

  • No communication with the BSI
  • Communication with milometer warning lights error
  • VAN line error
  • Control unit broken

Move on to Step

No communication with Body Computer error detected and/or VAN CONfor. network error and/or communication error with the instrument panel and/or control unit broken.

Move on to Step

4

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in the Milometer Warning Lights Node ambient check that the function in question is correctly activated in Active Diagnosis.

  • Autotest

Move on to Step

The component in question is not activated. It is not operated by the active diagnosis.

Replace the Milometer Warning Lights Node control unit.

6

SENSOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the operation of the pressure sensor, in particular the control device for the engine oil pressure level signal and the wiring.

Move on to Step

1. Engine oil pressure device faulty.

1. Replace the engine oil pressure device.

2. Gauge wiring and body computer faulty.

2. Repair wiring.

7

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
