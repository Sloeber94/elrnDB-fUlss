Applies to: all engines; all production periods

One of the electric front windows, left or right, is not working properly when the switch is pressed.

Applies to: all engines; all production periods

The electric window motor is operated directly by the relevant door node which is incorporated in a single assembly. The Door Node receives the window opening/closing command from the switch located in the control panel on the door. The Door Node transmits the request to the Body Computer Node which authorizes the Door Node to operate the window opening motor. The power supply for the door nodes is protected by a specific fuse housed in the Body Computer Node. The networks go on stand-by 30 mins after the engine is switched off. This makes it impossible to carry out the fault diagnosis. If a diagnostic session has to be opened, start up the engine to reawaken the networks

Applies to: all engines; all production periods
