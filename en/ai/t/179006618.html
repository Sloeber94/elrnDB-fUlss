ON BOARD DIGANOSTIC SYSTEM (EOBD) - Pollution control system efficiency check

INTRODUCTION

In order to further reduce the pollutant gases emitted by diesel vehicles an EOBD engine management system is used (European On Board Diagnosis) similar to the one already used on petrol versions. It should be pointed out that the EOBD system installed on the vehicle, depending on the version, conforms to directive 2002/80/CE Level A (EURO 3) or to directive 2002/80/CE Level B (EURO 4).

DESCRIPTION

This system allows the continuous fault diagnosis of the vehicle components related to emissions; it also signals the deterioration of these components by an amber yellow warning light in the instrument panel coming on.

The aim of the system is to:

- monitor system efficiency;

- signal when a malfunction causes an increase in emissions beyond the limit set by European regulations;

The system also has a diagnostic connector, interfaced with control equipment, that allows the error codes stored in the control unit memory to be read, together with a series of specific parameters for the fault diagnosis and operation of the engine.

In normal conditions, when the ignition key is turned to the ON position, the (amber yellow) warning light comes on, but should go off when the engine is started.

The warning light coming on initially indicates that it is working properly. If the warning light remains on constantly or comes on whilst driving (on some versions together with a message in the display) this signals a malfunction in the injection system / intake air circuit which could cause high exhaust emissions, a possible loss of performance, poor driveability and high consumption.

The prolonged use of the vehicle with the warning light on constantly could cause damage. Timely intervention to repair the fault that caused the warning light to come on is an obligation that depends on the laws and Highway Code in the country where the car is driven.

If the malfunction disappears, the warning light will only go out after the engine has been started 3 times and has reached operating temperature from cold.

The system memorizes and preserves the malfunction information for 40 warm up cycles (a warm up cycle refers to cold starting the engine and letting it reach operating temperature).

The vehicle has a diagnostic connector (the same as the one already used for the Examiner) that can interface with a piece of equipment known as a SCAN TOOL which allows the fault codes stored in the control unit memory to be read, together with a series of specific parameters for the fault diagnosis, the operation of the engine and the mileage since the warning light came on.

Directive EURO 3 (and higher) makes provision for these parameters to be visible, therefore it is possible for any authorities that check on vehicles in circulation to "read" these parameters (Forces of Law and Order, etc.).
