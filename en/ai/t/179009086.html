Applies to: engines: 2.0 16V JTD, 2.2 16V JTD; all production periods; only with equipment: Electric seats with memory and MY 2005

The vehicle can be fitted with electrically adjustable front seats, in particular:

  • lengthwise movement (forwards/backwards);
  • height adjustment;
  • backrest adjustment

Each of the adjustments is carried out by a specific electric motor.

On the versions with "seats with a memory", 4 different positions can be memorized for the driver's seat:

  • two linked to the remote controls for opening/closing the doors: when the doors are locked using the remote control, the position of the seat and the door mirrors is acquired by the remote control. When the doors are unlocked using the remote control, the seat and the door mirrors resume the position memorized previously;
  • two linked to the memory buttons on the actual seat.

the positions memorized also include the position of the door mirrors.

See E3032 DOOR MIRROR ADJUSTMENT

The adjustments can be made with the ignition key in position M and for about 1 minute after the key is turned to position S.

This complex logic is managed by the seats/mirrors with memory control unit which converses with the Body Computer via the CAN.

The circuit is protected by a specific fuse, located in the additional fuse box.
