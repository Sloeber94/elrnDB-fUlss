Removing

Refitting

1. Release the side pin for the guide winder from the housing by pressing the pin.

2. Release the blind pin as illustrated.

Applies to: all engines; all production periods

Refitting

Removing

1. Load the blind spring using the right pin. With the pin pressed, rotate the terminal in a clockwise direction to remove it to lock the spring.

1. Repeat the operation until the spring is completely taut.

Applies to: all engines; all production periods

- Insert the terminal with the spring compressed and then the side pin taking care not to release the spring loading.

- Refit the guide in the reverse order to the removal.

- Test the sliding and rewinding, making sure that the spring is taut.
