Applies to: engines: 2.0 16V JTD, 2.2 16V JTD; all production periods; only with equipment: MY 2005

The door node control units control the operation of the driver and passenger side front electric window motors. The electric motors for the front windows are incorporated in the door nodes.

Information on the current position of the windows and the opening/closing commands through the operation of the remote control is provided via the CAN.

The driver's electric window is equipped with a device (which operates when the engine is started) that works continuously according to the following logic:

  • if the button is pressed is between 60 and 300 milliseconds, operation is manual. the glass goes up/down only with the key pressed;
  • f the key is pressed for longer than 300 milliseconds, operation is automatic: even if the button is released, the glass continues to move up/down until the end of travel position is reached or until the intervention of the anti-crush safety system (if fitted);
  • pressing the button again whilst the window is moving stops it in the position it is in;
  • if the button is pressed for less than 60 milliseconds, this is ignored (it is treated as an accidental knock).

The electric windows are equipped with an anti-crush safety system: the control unit on the door is capable of detecting the presence of any obstacles whilst the window is closing; in this case it interrupts the travel of the window and reverses it immediately.

With the key in position S, the windows remain activated for around 1 minute.

When the remote control button is pressed in order to activate the "passenger compartment ventilation" function, the front and rear side windows open completely to allow outside air to enter the passenger compartment.

See E3040 CENTRAL LOCKING

After the battery has been disconnected, if the electric windows do not work when there is an attempt to close them, the system must be initialized: release the control and operate it a second time until the roof is completely closed, keeping it activated for more than a second after the end of travel position has been reached; in this way the system will resume normal operation.
